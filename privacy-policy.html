Privacy Policy

Effective Date: March 20, 2026

This Chrome extension does not collect, store, transmit, or share personal information.

Information Collection

The extension does not collect personally identifiable information, authentication data, financial data, health information, precise location, browsing history, or user communications.

Data Processing

Any data processed by this extension is handled locally in your browser for core functionality and is not sent to external servers.

Permissions

The extension requests the following permissions, each required for core functionality:

  • Debugger: Used to attach the Chrome DevTools debugger protocol to the current tab in order to capture and display WebSocket frames. This only activates when the user opens the Conga Debugger DevTools panel and a page uses WebSocket connections.

Third-Party Services

This extension does not use third-party analytics, tracking, or advertising services.

Changes to This Policy

This policy may be updated periodically. Any changes will be posted on this page with an updated effective date.
